# Seed-Fixtures (Demo)

Dateien, die `app:demo:sync` in den Dateispeicher (`MediaStorageService`) übernimmt. Der SHA-256-Wert jeder Datei steht im Katalog
(`organisations.json`); `app:demo:verify` meldet abweichende oder fehlende Dateien.

| Datei | Verwendung | Quelle / Nutzung |
| --- | --- | --- |
| `event-gelaende.webp` | Geländekarte des Szenarios `grossanlass-event` (Hintergrund, 943×721 px) | Zusammenstellung öffentlich zugänglicher Geodaten von [geo.admin.ch](https://map.geo.admin.ch) (Luftbild) mit eingezeichneten Zonen, erstellt vom Projekt. Quellenangabe: **© swisstopo** (Bundesamt für Landestopografie). |

## Nutzungsbedingungen swisstopo

Die kostenlosen Geodaten und Geodienste von swisstopo (Open Government Data) dürfen genutzt, verbreitet, bearbeitet und kommerziell genutzt
werden; eine Quellenangabe ist Pflicht («Bundesamt für Landestopografie swisstopo» oder «©swisstopo»). Siehe
<https://www.swisstopo.admin.ch/de/nutzungsbedingungen-kostenlose-geodaten-und-geodienste>.

Die Karte trägt die Quellenangabe im Namen («Gelände (© swisstopo)») und ist damit überall sichtbar, wo sie angezeigt wird.
Der Luftbild-Layer entspricht nach Angabe des Projekts SWISSIMAGE; die genaue Layer-Herkunft wurde nicht aus der Datei selbst geprüft.
