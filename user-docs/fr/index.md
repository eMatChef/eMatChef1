# Aide eMatChef

eMatChef est le lieu commun pour le **matériel, le stockage, les prêts et les activités** — pour associations, sections et locations. Tout se passe dans le navigateur.

Ce site est l’**aide produit publique**. Il ne contient pas de données d’organisation ou d’utilisateur.

## Aide et visites guidées

| | Où | Pour quoi |
|---|---|---|
| **Aide** | ces pages | lire, partager, assistants avec une capture d’écran |
| **Visites** | dans l’app, Aide → Visites | pas à pas dans l’interface réelle |

Le bouton **Aide** de l’app ouvrira plus tard la page correspondante ici. Les visites guidées restent dans l’app.
