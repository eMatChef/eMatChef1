# Visites et aide

Les deux existent, avec des rôles différents.

## Visites (dans l’app)

Les visites guidées parcourent l’**interface actuelle** : clics, dialogues, checklist. Elles restent dans l’app (`Aide → Visites`) et ne font pas partie de ce site public.

## Cette aide (publique)

Ici, les **déroulements par écrit** : sans connexion, sans données de section. Pour relire, partager un lien, ou qu’un assistant lise la page à côté d’une capture d’écran.

## Dans l’app

- Bouton **Aide** (en bas à droite) : page publique correspondante
- Menu **Aide → Visites** : démarrer une visite guidée
- Menu **Aide → Documentation** : aperçu avec des liens vers ici
