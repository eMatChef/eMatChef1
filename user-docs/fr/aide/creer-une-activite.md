# Créer une activité

Une **activité** est un camp, un événement, une mission ou un prêt interne. Tu y associes du matériel, tu soumets, tu prépares, puis tu réintègres le stock au retour.

## En bref

1. Choisir la section dans l’app.
2. Ouvrir **Activités**.
3. Créer une nouvelle activité et fixer les dates.
4. Associer le matériel et soumettre (selon le rôle).

Le chemin exact dans *ton* interface est dans la **visite** sous Aide → Visites. Cette page est le résumé public.
