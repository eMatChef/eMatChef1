# Prêt externe

Un **prêt externe** est une activité pour des clients hors de ta propre section — avec demande, contrôle, et souvent une facture.

## En bref

1. Choisir la section dans l’app.
2. Créer une nouvelle activité de type prêt externe / location.
3. Saisir les dates et la demande de matériel.
4. Soumettre pour que le responsable matériel puisse contrôler et préparer.

La visite dans l’app montre les boutons de la version actuelle. Complète cette page une fois le flux figé.
