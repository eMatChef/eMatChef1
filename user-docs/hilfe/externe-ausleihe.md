# Externe Ausleihe

Eine **externe Ausleihe** ist eine Aktivität für Kundinnen und Kunden ausserhalb der eigenen Abteilung — mit Wunsch, Prüfung und oft Rechnung.

## Kurz

1. In der App die Abteilung wählen.
2. Eine neue Aktivität vom Typ externe Ausleihe / Vermietung anlegen.
3. Zeitraum und Materialwunsch erfassen.
4. Einreichen, damit die Materialwartung prüfen und packen kann.

Die geführte Tour in der App zeigt die Buttons in der aktuellen Version. Ergänze diese Seite, sobald der Ablauf feststeht.
