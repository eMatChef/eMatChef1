# Aktivität anlegen

Eine **Aktivität** ist ein Einsatz, Lager, Event oder eine interne Ausleihe. Du ordnest Material zu, reichst ein, packst und buchst bei der Rückgabe wieder ein.

## Kurz

1. In der App die Abteilung wählen.
2. **Aktivitäten** öffnen.
3. Neue Aktivität anlegen und Zeitraum setzen.
4. Material zuordnen und einreichen (je nach Rolle).

Die genaue Klickfolge in *deiner* Oberfläche zeigt die **Tour** unter Hilfe → Touren. Diese Seite bleibt die öffentliche Kurzfassung.
