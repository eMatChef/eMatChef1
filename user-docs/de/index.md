# eMatChef Hilfe

eMatChef ist die gemeinsame Stelle für **Material, Lager, Ausleihen und Aktivitäten** — für Vereine, Abteilungen und Vermietungen. Alles läuft im Browser.

Diese Website ist die **öffentliche Produkthilfe**. Sie enthält keine Organisations- oder Benutzerdaten.

## Hilfe und Touren

| | Wo | Wofür |
|---|---|---|
| **Hilfe** | diese Seiten | nachlesen, teilen, Assistenten mit Screenshot |
| **Touren** | in der App unter Hilfe → Touren | Schritt für Schritt in der echten Oberfläche |

In der App führt der Button **Hilfe** später auf die passende Seite hier. Die geführten Touren bleiben intern.
