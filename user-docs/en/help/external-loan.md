# External loan

An **external loan** is an activity for customers outside your own department — with a request, a check, and often an invoice.

## Short version

1. Choose the department in the app.
2. Create a new activity of type external loan / rental.
3. Enter dates and the material request.
4. Submit so materials management can check and pack.

The in-app tour shows the buttons in the current version. Expand this page once the flow is settled.
