# Create an activity

An **activity** is a camp, event, duty or internal loan. You assign materials, submit, pack, and book them back in on return.

## Short version

1. Choose the department in the app.
2. Open **Activities**.
3. Create a new activity and set the dates.
4. Assign materials and submit (depending on your role).

The exact clicks in *your* UI are in the **tour** under Help → Tours. This page is the public short version.
