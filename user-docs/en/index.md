# eMatChef Help

eMatChef is the shared place for **inventory, storage, loans and activities** — for clubs, departments and rental teams. It runs in the browser.

This site is the **public product help**. It does not contain organisation or user data.

## Help and tours

| | Where | What for |
|---|---|---|
| **Help** | these pages | reading, sharing, assistants with a screenshot |
| **Tours** | in the app under Help → Tours | step by step in the real UI |

The in-app **Help** button will later open the matching page here. Guided tours stay inside the app.
