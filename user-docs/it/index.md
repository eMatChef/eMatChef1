# Guida eMatChef

eMatChef è il posto condiviso per **materiale, magazzino, prestiti e attività** — per associazioni, sezioni e noleggi. Funziona nel browser.

Questo sito è la **guida prodotto pubblica**. Non contiene dati di organizzazione o utenti.

## Guida e tour

| | Dove | A che serve |
|---|---|---|
| **Guida** | queste pagine | leggere, condividere, assistenti con uno screenshot |
| **Tour** | nell’app, Guida → Tour | passo dopo passo nell’interfaccia vera |

Il pulsante **Guida** nell’app aprirà più avanti la pagina corrispondente qui. I tour guidati restano nell’app.
