# Prestito esterno

Un **prestito esterno** è un’attività per clienti fuori dalla propria sezione — con richiesta, controllo e spesso una fattura.

## In breve

1. Scegliere la sezione nell’app.
2. Creare una nuova attività di tipo prestito esterno / noleggio.
3. Inserire le date e la richiesta di materiale.
4. Inviare così la gestione materiale può controllare e preparare.

Il tour nell’app mostra i pulsanti della versione attuale. Completa questa pagina quando il flusso è stabile.
