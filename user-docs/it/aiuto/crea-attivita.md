# Creare un’attività

Un’**attività** è un campo, un evento, un servizio o un prestito interno. Assegni il materiale, invii, prepari e al rientro lo registri di nuovo.

## In breve

1. Scegliere la sezione nell’app.
2. Aprire **Attività**.
3. Creare una nuova attività e impostare le date.
4. Assegnare il materiale e inviare (a seconda del ruolo).

Il percorso esatto nella *tua* interfaccia è nel **tour** sotto Guida → Tour. Questa pagina è il riassunto pubblico.
