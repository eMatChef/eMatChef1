# Tour e guida

Hanno compiti diversi.

## Tour (nell’app)

I tour percorrono l’**interfaccia attuale**: clic, finestre, checklist. Restano nell’app (`Guida → Tour`) e non fanno parte di questo sito pubblico.

## Questa guida (pubblica)

Qui ci sono i **flussi per iscritto**: senza login, senza dati della sezione. Per rileggere, condividere un link o far leggere la pagina a un assistente insieme a uno screenshot.

## Nell’app

- Pulsante **Guida** (in basso a destra): pagina pubblica corrispondente
- Menu **Guida → Tour**: avviare un tour guidato
- Menu **Guida → Documentazione**: panoramica con i link a queste pagine
