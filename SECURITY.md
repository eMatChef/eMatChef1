# Security Policy

## Supported versions

Security fixes target the current production line (`prod` / live App). Development happens on `develop`.

| Branch | Support |
|--------|---------|
| `prod` | Security fixes |
| `staging` | Pre-production |
| `develop` | Active development |

## Reporting a vulnerability

Please report security issues **privately** — do not open a public GitHub Issue for vulnerabilities.

Preferred options:

1. **GitHub private vulnerability reporting** — on the repository: *Security → Advisories → Report a vulnerability* (or the “Report a vulnerability” button on the Security tab).
2. Or contact the maintainers via the eMatChef organization on GitHub.

Please include:

- Affected component (frontend / API / deploy)
- Steps to reproduce (minimal)
- Impact assessment (data exposure, privilege escalation, …)
- Your contact for follow-up

We aim to acknowledge reports within a few business days and will coordinate disclosure after a fix is available.
